# CPH Trip

Group map for a Copenhagen trip: everyone shares their location, the group picks a place, and each person sees the metro, S-train and walking route to get there.

Open it on any phone: https://achi-sal.github.io/cph-trip/

- **iPhone:** open the link in Safari → Share → Add to Home Screen.
- **Android:** open the link in Chrome → Install app, or install `CPH-Trip.apk`.

Join a friend's trip with the trip code from their invite. Locations are encrypted with the trip code before they're sent through public Nostr relays.
